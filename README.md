# healthcare-dashboard

## 🚀 Description

A responsive healthcare dashboard that displays patient information, diagnosis history, and medical metrics in an interactive UI. The application fetches real-time patient data from an API and visualizes health metrics such as blood pressure using dynamic charts.

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Charts: Chart.js
* API Integration: Fetch API (REST)
* Styling: Custom CSS

## ✨ Features

* Patient list with dynamic selection
* Real-time data fetching from API
* Interactive blood pressure chart visualization
* Display of vital metrics (heart rate, temperature, respiratory rate)
* Diagnostic history and lab results
* Clean and responsive dashboard UI

## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
4. Ensure internet connection for API data loading

## 🌐 API Used

Data fetched from external healthcare API with authentication
